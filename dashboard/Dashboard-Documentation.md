# SOC Monitoring Dashboard

## Overview

The SOC Monitoring Dashboard provides a centralized view of security-relevant Windows and Sysmon telemetry collected from the Windows 11 monitored endpoint.

The dashboard was created in Splunk Enterprise to help a SOC analyst quickly monitor process activity and identify events that may require further investigation.

## Dashboard Name

`SOC Monitoring Dashboard`

## Dashboard Purpose

The dashboard provides visibility into:

* PowerShell activity
* Windows Command Shell activity
* Process creation
* Sysmon event distribution

The dashboard uses Splunk SPL searches to retrieve and display relevant security telemetry.

## 1. PowerShell Process Monitoring

### Purpose

This panel monitors PowerShell process activity generated on the Windows 11 endpoint.

### SPL Query

```spl id="8c5f2u"
index=main sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*powershell*" | table _time User ParentImage CommandLine
```

### Important Fields

* `_time` — Time when the event occurred
* `User` — Account associated with the process
* `ParentImage` — Parent process
* `CommandLine` — Command used to start the process

### MITRE ATT&CK

**T1059.001 — PowerShell**

## 2. CMD Process Monitoring

### Purpose

This panel monitors Windows Command Shell activity.

### SPL Query

```spl id="q8p3jk"
index=main sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*cmd.exe*"
```

### SOC Relevance

CMD activity can provide useful process telemetry for investigating command execution on a Windows endpoint.

### MITRE ATT&CK

**T1059.003 — Windows Command Shell**

## 3. Process Creation Monitoring

### Purpose

This panel provides visibility into Sysmon Process Creation events.

### SPL Query

```spl id="v5n7sd"
index=main sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1
```

### Event

**Sysmon EventCode 1 — Process Creation**

### Important Fields

* Timestamp
* User
* Process Image
* Parent Image
* Command Line
* EventCode

### SOC Relevance

Process creation telemetry helps an analyst understand which processes were executed, by which user, and how they were launched.

## 4. Sysmon EventCode Monitoring

### Purpose

This panel shows the distribution of Sysmon EventCodes collected by Splunk.

### SPL Query

```spl id="m3x8qa"
index=main sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" | stats count by EventCode
```

### SOC Relevance

This view helps the analyst understand which types of Sysmon telemetry are being generated by the monitored endpoint.

## Dashboard Panels

The current dashboard contains monitoring panels for:

1. PowerShell Process Monitoring
2. CMD Process Monitoring
3. Process Creation Monitoring
4. Sysmon EventCode Monitoring

These panels provide a centralized view of process and Sysmon telemetry.

## Detection and Alerting

The dashboard displays the results of detection searches.

Detection searches identify security-relevant activity in collected telemetry.

Automated alert creation was not enabled in the current Splunk Free lab environment.

Therefore, the dashboard is used for monitoring and investigation rather than claiming automated alert notification.

## Investigation Workflow

When suspicious activity appears in the dashboard, the analyst can investigate the underlying events using Splunk searches.

The investigation can include:

* Timestamp
* User
* Process Image
* Parent Process
* Command Line
* EventCode
* Authentication events
* Related system activity

The analyst can then determine whether the activity is expected or requires further investigation.

## Limitations

The current dashboard focuses primarily on Sysmon Process Creation and related process telemetry.

Windows authentication events such as Event ID 4624 and 4625 were investigated separately using Splunk searches but are not currently included as dashboard panels.

Automated alerting was also not enabled in the current Splunk Free lab environment.

## Conclusion

The SOC Monitoring Dashboard provides a centralized monitoring interface for the Home SOC Lab.

It demonstrates how Splunk can transform collected Windows and Sysmon telemetry into useful monitoring views that support detection and investigation.

The dashboard forms an important part of the SOC workflow:

**Telemetry Collection → Detection → Dashboard Monitoring → Investigation → Incident Response**
